# 測試模式的流程資料

每個原型一份 `flows/<資料夾名>.js`，只在測試模式（`?test=1`）由 `../kit.js` 載入：

```js
PP.register('<資料夾名>', {
  name: '畫面名稱',
  hints: [ /* 自由探索的提示 */ ],
  tours: [ /* 一步一步的引導 */ ]
});
```

## hints：自由探索的提示點

| 欄位 | 意思 |
|---|---|
| `sel` | 要提示的元素（CSS 選擇器，通常是 `[data-key="…"]`） |
| `t`、`d` | 提示的標題與一句說明 |
| `by` | 依元素自己的字決定提示：`{'報到': [標題, 說明, 引導id]}`，以元素文字開頭比對，長的先比 |
| `tour` | 這個提示連到哪個引導；點提示點會出現「一步一步帶我做」 |
| `quiet` | 只在滑鼠移上去或聚焦時出現提示，不畫圓點 |
| `stub` | 原型沒做的功能：畫虛線框，提示「示範未開放」 |

同一個流程只在第一個看得到的入口畫一個圓點。

## minWidth：要寬螢幕的流程

`PP.register` 的資料或單一引導可以寫 `minWidth: 720`：畫面比這窄時（例如手機上只能查看的管理畫面），開場卡改說「這個流程要在電腦或橫放的平板上操作」，只給「知道了」，不讓引導卡在做不到的步驟。單一引導寫 `minWidth: 0` 可以不受整份的設定限制。

## tours：引導

越細越好：**一步只做一個動作，或只說明一件事**。每個動作之後，用 `info` 步驟亮起剛剛改變的地方並說明（臉環 1/6 → 2/6、後果預覽、確認視窗的「原本／改成」）。安全提醒（會咬人等）一定要有一步把它亮起來。口吻：店家畫面說「寵物」，飼主畫面說「毛孩」。

```js
{id: 'checkin', title: '幫阿福報到並記錄現況', who: '櫃台阿凱', query: {role: 'clerk'},
 scene: '開場卡上的情境：你是誰、現在發生什麼事、要做什麼',
 outro: '總結卡上的一段話：做完之後改變了什麼',
 steps: [
  {sel: '[data-key="p-afu"]', t: '在今日預約找到阿福，按「報到」', d: '一句說明'},
  {sel: '[data-key="f-afu"]', info: true, t: '阿福進了「店裡的寵物」：臉環 1/6', d: '說明剛剛改變了什麼'},
  {sel: '.ckitem:has([data-key="ck-皮膚-正常"])', group: true, t: '皮膚：選「正常」',
   until: {checked: '[data-key="ck-皮膚-正常"]'}, demo: {click: '[data-key="ck-皮膚-正常"]'}},
  {sel: '#wk-phone', t: '輸入手機', fill: {value: '0922610552', label: '0922610552（楊小姐）'},
   until: {value: ['#wk-phone', '^09\\d{8}$']}},
  {sel: '#ho-pad', group: true, t: '在框內簽名', until: {enabled: '[data-key="ho-next"]'}, demo: {draw: '#ho-canvas'}}
 ]}
```

| 引導欄位 | 意思 |
|---|---|
| `title`、`who` | 流程名稱、你扮演誰（開場卡寫「你是…」） |
| `scene` | 開場卡的情境說明；開場卡也會列出全部步驟名稱，按「開始」才進第 1 步 |
| `outro` | 總結卡的一段話。總結卡列出做完的每一步，給「練習下一個流程」（同一頁的下一個引導）和「給意見」，沒有評分 |
| `query` | 這個引導要的網址參數，例如身分；值寫 `null` 表示網址不能有這個參數（重新載入時會拿掉）。從提示點或測試分頁開始時，網址不符或受測者已經點過原型，會先重新載入，讓原型回到剛打開的樣子 |
| `life` | `true` 表示這是導演頁（「毛毛的一天」`prototypes/life/`、「王太太收不到簽署連結」`prototypes/sign-link/`、「毛孩日和開張」`prototypes/open-day/`、「一份契約的一生」`prototypes/contract-life/`、「毛孩日和的月費」`prototypes/monthly-fee/`、「阿福的過敏」`prototypes/allergy/`、「臨時公休那天」`prototypes/closure/`、「LINE 當機的那一小時」`prototypes/line-down/`、「毛毛住兩晚」`prototypes/stay/`、「郭太太的刪除申請」`prototypes/erase/`、「毛孩日和被停權到恢復」`prototypes/suspend/`、「臨時取消和沒來的那天」`prototypes/late-cancel/`、「阿楷離職那天」`prototypes/last-day/`、「貓咪剃毛上架」`prototypes/new-service/`、「簡訊用量快爆了」`prototypes/sms-quota/`）其中一幕的引導：測試入口頁、測試分頁和「練習下一個流程」都不列它，只由導演頁用 `?life=<幕>&test=1&tour=<id>` 開啟；在導演頁的框裡，kit 會把每個事件 postMessage 給導演頁，做完時提示按導演頁的「下一幕」 |
| `seed` | 開場情境：重新載入時帶上的網址參數，給「讀完就把參數從網址拿掉」的原型用（例如方案與用量的 `?s=big`）。kit 看的是頁面打開時的網址，不是原型改寫後的網址，所以不會一直重新載入 |

| 步驟欄位 | 意思 |
|---|---|
| `sel` | 這一步亮起來的元素。預設取第一個可以用的；`group: true` 則框住全部符合的元素。label 裡的 input 會改框 label |
| `until` | 什麼時候換下一步。不寫就是「點了這個元素」；也可以用 `{enabled: sel}`、`{appear: sel}`、`{value: [sel, 正規式]}`、`{checked: sel}`（勾選、aria-checked 或 aria-pressed） |
| `fill` | 要輸入的示範值，步驟卡上會有「幫我填」；`into` 可以指定填到哪個欄位 |
| `info` | 純說明，步驟卡上出現「下一步」或「完成」 |
| `settle` | 這一步開始前要擋住幾毫秒（動作預設 650、說明預設 300），這段時間亮區外框會呼吸、步驟卡寫「準備中…」 |
| `timeout` | 等這一步的元素出現最多等多久（預設 6000 毫秒），超過就顯示「畫面好像沒有照預期變化」 |
| `minWidth`、`maxWidth` | 這一步只在畫面至少／最多這麼寬時出現，例如只有窄版才有的「回到列表」按鈕。頁面打開時就決定，步數跟著變 |
| `demo` | 只給自動測試用：`{click: sel}`、`{clickAll: sel}`、`{scroll: sel}`、`{draw: canvas}` |

步驟卡可以展開「全部步驟」：做完的打勾、可以點開再看一次說明（只看文字，不還原操作），目前這步加粗。
重新整理頁面時原型會回到一開始，所以不會硬接原本的步驟，而是問「要從頭開始嗎？」。

## 驗證

`test-kit/tests/test-kit.js` 會從開場卡按「開始」，依每一步的 `demo`（沒有 `demo` 就點 `sel`）把每個引導從頭走到總結卡，每一步都要在時間內出現。原型改版、選擇器失效時，這項測試會變紅。

## 測試入口頁（`prototypes/test.html`）

入口頁直接載入這裡的每一份 flows 檔，所以新增或改名引導不用改入口頁。要注意兩件事：

- **新的原型**：把資料夾名加進 `test.html` 的 `ENDS`（順序就是建議做的順序）。
- **新的人物**：`who` 用名字開頭對照到受測者身分（飼主、現場店員、店家管理者、寵派員工），對照表是 `test.html` 的 `ROLES`。新名字沒加進去會被歸到「其他」，`test-kit/tests/entry-page.js` 會變紅。

入口頁的任務連結會帶上引導的 `query` 和 `seed`，讓 kit 不必再重新載入，受測者按「上一頁」就能回到入口頁。主持人可以挑任務組成 `test.html?set=<資料夾>:<引導id>,…&tester=<代號>` 給受測者；代號存在 `pp-tester`，kit 匯出回饋時會帶上。
